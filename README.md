# ひろ先生のマイクラ教室

保護者向けの1ページサイトです。このフォルダーのファイルを同じ場所に置けば、静的サイトとして表示できます。専用サーバーやビルド作業は不要です。

## 公開URL

https://hityas.github.io/hiro-play-class/

GitHub Pagesで一般公開しています。リンクを知っている人はログインなしで閲覧できます。

## 更新する場所

- 文章・色・レイアウト: `index.html`
- メイン画像: `hero-world.webp`（生成したイメージイラスト）
- 卒業シーン: `graduation-scene.webp`（授業スクリーンショットをもとに表示名などを除いて再構成）
- アイコン: `favicon.svg`

同じファイル構成のまま、別の静的ホスティングサービスへ移すこともできます。

## 公開前に確認したいこと

授業料・体験料・授業回数・必要な環境・申込フォームのURL・メールアドレスが現行の案内と一致しているか確認してください。授業記録に含まれていた受講者の個人情報や元の資料はこのサイトに入れていません。
